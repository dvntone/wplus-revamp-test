📡 wscan+

Cross-platform Wi-Fi Intrusion Detection System for Windows & Android

⬇ Download GitHub Changelog

Features

🛡️

Attack Heuristics

Detects Evil Twin / Karma, Deauth Flooding, PMKID Sniffing, and KRACK in real time.

🤖

Gemini AI Analysis

Send threat logs to Google Gemini for natural-language risk assessment and mitigation advice.

🔗

Companion Mode

Android app forwards mobile scan results to the Windows desktop via a local HTTP relay for combined analysis.

☁️

Cloud Sync

Firebase Realtime Database / Firestore sync keeps threat logs available across devices.

📊

Export

Export threat logs to .csv or raw captures to .pcap (Wireshark-compatible).

🔍

OUI Lookup

Local IEEE OUI SQLite database flags vendor mismatches — a key indicator of MAC spoofing.

Detected Attack Types

AttackDetection MethodSeverity
Evil Twin / Karma Duplicate SSID broadcasting from a new BSSID; optional OUI mismatch HIGH
Deauth Flood ≥15 Deauth/Disassoc frames within a 10-second window per BSSID HIGH / MEDIUM
PMKID Sniffing EAPOL Handshake M1 from an unassociated client MAC MEDIUM
KRACK Duplicate EAPOL Handshake M3 replay counter (nonce reuse) HIGH

Requirements

🤖 Android

  • Android 10 (API 29)+
  • Shizuku (recommended)
  • Root + tcpdump (optional)
  • Internet for Firebase / Gemini

🪟 Windows

  • Windows 11 / 10 (21H2+)
  • .NET 8 Desktop Runtime
  • Npcap 1.80+
  • WSL2 (optional, for monitor mode)
